# Bus Truth

Bus Truth measures how reliable Halifax Transit actually is. It records the live
GTFS-Realtime feeds continuously, compares what the buses actually did against the published
schedule and against the agency's own live predictions, and publishes the gap. Five things
come out of it: a live map, route on-time performance, bunching, ghost buses (scheduled trips
that never ran), and prediction accuracy. Everything is derived from raw feed snapshots that
are archived as they arrive and kept, so every number can be traced back to the evidence it
came from and recomputed when a rule changes.
